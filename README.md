# Abdullah Rashid's Portfolio

My personal portfolio website, showcasing my background, software projects, and interests in back-end development and applied machine learning. I am a Computer Science student at the University of Calgary, seeking a Summer 2027 internship or co-op.

This repository contains the source code for the website, built from my own GUI design sketch.

## Features

- **Home** introduces my academic background, development experience, and career interests, with links to my GitHub and LinkedIn profiles.
- **Projects** highlights Signal, Spring Store, Vehicle Dealership, and Finding X through short descriptions, technology lists, and repository links.
- **Resume** provides a dedicated page for my resume, with content to be added.
- **Contact** offers a direct email link.
- **Responsive design** adapts the layout for desktop and mobile screens.
- **Light and dark themes** use a black base and blue accents, with the selected theme saved between visits.

## Built with

- **Python and Flask** for routing and serving pages.
- **Jinja** for reusable templates and project cards.
- **HTML and CSS** for page structure, styling, and responsive layouts.
- **JavaScript** for theme switching and saving preferences.
